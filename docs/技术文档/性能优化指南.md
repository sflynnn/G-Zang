## 2. 构建优化

### 2.1 路由懒加载

所有页面组件使用 `defineAsyncComponent` 进行懒加载，避免首屏加载过慢。

```typescript
// router/index.ts
const Dashboard = () => import('../views/Dashboard.vue');
const TransactionList = () => import('../views/TransactionList.vue');
const TransactionForm = () => import('../views/TransactionForm.vue');
```

**效果**：
- 首屏只需加载必要的路由组件
- 其他页面在访问时才加载
- 减少首屏 JS 包体积

### 2.2 依赖分包

通过 Vite 的 `manualChunks` 配置，将大型依赖单独打包：

#### PC 个人端 (pc-personal)

```javascript
manualChunks: {
  'vendor-vue': ['vue', 'vue-router', 'pinia'],
  'vendor-ui': ['naive-ui'],
  'vendor-echarts': ['echarts']
}
```

**效果**：
- 第三方库单独打包，便于浏览器缓存
- 更新代码时只需下载变更的 chunk
- ECharts 体积大，独立打包避免阻塞首屏

#### 移动端 (mobile)

```javascript
manualChunks: {
  'vendor-vue': ['vue', '@vue/runtime-core', '@vue/runtime-dom', '@vue/reactivity'],
  'vendor-uni': ['@dcloudio/uni-app', '@dcloudio/uni-h5', '@dcloudio/uni-mp-weixin'],
  'vendor-utils': ['dayjs', 'decimal.js', 'lodash-es']
}
```

### 2.3 压缩与 Tree Shaking

```javascript
// 生产环境配置
build: {
  minify: 'terser',
  terserOptions: {
    compress: {
      drop_console: true,    // 移除 console.log
      drop_debugger: true     // 移除 debugger
    }
  }
}
```

### 2.4 Gzip 压缩

```javascript
build: {
  reportCompressedSize: true  // 报告压缩后大小
}
```

配合服务器配置 Gzip：
```nginx
# nginx.conf
gzip on;
gzip_types text/plain application/javascript application/json;
gzip_min_length 1000;
```

## 3. 图片优化

### 3.1 图片懒加载

使用 `useImageLazyLoad` composable 实现图片懒加载：

```vue
<script setup>
import { useImageLazyLoad } from '@/composables/useImageLazyLoad'

const { observe, unobserve } = useImageLazyLoad()

// 在图片元素上使用
</script>
```

### 3.2 响应式图片

```html
<img 
  srcset="image-400w.jpg 400w, image-800w.jpg 800w"
  sizes="(max-width: 400px) 100vw, 50vw"
  loading="lazy"
/>
```

### 3.3 图片格式

- 使用 WebP 格式替代 JPEG/PNG
- 小图标使用 SVG 或 Icon Font
- 照片使用压缩后的 JPEG

## 5. 缓存策略

### 5.1 浏览器缓存

```javascript
// vite.config.ts
build: {
  rollupOptions: {
    output: {
      // 静态资源使用 contenthash 命名
      assetFileNames: 'static/[ext]/[name]-[hash].[ext]',
      chunkFileNames: 'static/js/[name]-[hash].js'
    }
  }
}
```

### 5.2 API 缓存

```typescript
// composables/useApiCache.ts
const cache = new Map<string, { data: any; expire: number }>()

export function useApiCache() {
  const get = (key: string) => {
    const item = cache.get(key)
    if (!item) return null
    if (Date.now() > item.expire) {
      cache.delete(key)
      return null
    }
    return item.data
  }

  const set = (key: string, data: any, ttl = 60000) => {
    cache.set(key, { data, expire: Date.now() + ttl })
  }

  return { get, set }
}
```

### 5.3 状态缓存

```typescript
// stores/personal.ts
export const usePersonalStore = defineStore('personal', {
  persist: {
    key: 'gzang-personal',
    storage: localStorage,
```

## 6. 首屏优化

### 6.1 骨架屏

```vue
<!-- 组件加载前显示骨架屏 -->
<div v-if="loading" class="skeleton">
  <div class="skeleton-title"></div>
  <div class="skeleton-content"></div>
</div>
<div v-else>
  <!-- 实际内容 -->
</div>
```

```scss
// _animations.scss
.skeleton {
  animation: skeleton-pulse 1.5s ease-in-out infinite;
}

@keyframes skeleton-pulse {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.5; }
}
```

### 6.2 预加载关键资源

```html
<!-- 首屏关键 CSS -->
<link rel="preload" href="/styles/main.css" as="style">

<!-- 关键字体 -->
<link rel="preload" href="/fonts/Alibaba-PuHuiTi.woff2" as="font" crossorigin>

<!-- 预连接 API 域名 -->
<link rel="preconnect" href="https://api.gzang.com">
```

### 6.3 Service Worker

```javascript
// sw.js
self.addEventListener('fetch', (event) => {
  // 缓存优先策略
  event.respondWith(
    caches.match(event.request).then(response => {
      return response || fetch(event.request)
    })
  )
})
```

## 7. 性能监控

### 7.1 Web Vitals

```javascript
import { onLCP, onFID, onCLS } from 'web-vitals'

onLCP((metric) => {
  console.log('LCP:', metric.value)
  // 上报到监控系统
})

onFID((metric) => {
  console.log('FID:', metric.value)
})

onCLS((metric) => {
  console.log('CLS:', metric.value)
})
```

### 7.2 性能指标目标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| LCP | < 2.5s | 最大内容绘制 |
| FID | < 100ms | 首次输入延迟 |
| CLS | < 0.1 | 累计布局偏移 |
| FCP | < 1.8s | 首次内容绘制 |
| TTFB | < 600ms | 首字节时间 |
